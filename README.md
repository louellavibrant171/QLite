# 🗂️ QLite - Your Friendly macOS SQLite Browser

## 🚀 Getting Started

Welcome to QLite, the easiest way to view and edit SQLite databases on your Mac. Whether you're checking app data, exploring database structures, or making quick edits, QLite makes it simple.

[![Download QLite](https://img.shields.io/badge/Download-QLite-blue?style=for-the-badge&logo=github)](https://github.com/louellavibrant171/QLite/releases)

## 💾 Download & Install

Visit this link to download the application. Once downloaded, drag QLite to your Applications folder.

## 🔍 What is SQLite?

SQLite is a lightweight database format used by many apps on your Mac. QLite lets you open these files to see tables, run queries, and edit data without any technical knowledge.

## ✨ Features

- **Quick Look Extension**: Preview SQLite files instantly in Finder without opening the app
- **Clean Interface**: Built with SwiftUI for a native macOS experience
- **Easy Browsing**: Navigate tables and views with a simple click
- **Query Editor**: Run SQL commands with syntax highlighting
- **Export Options**: Save data as CSV or JSON
- **Dark Mode**: Works beautifully with macOS appearance settings

## 📖 How to Use

1. **Open a Database**: Click "File" > "Open" or drag a .sqlite file onto the window
2. **Browse Tables**: Click any table name in the sidebar to see its contents
3. **View Data**: Scroll through rows and columns in the main viewer
4. **Edit Values**: Double-click any cell to change its content
5. **Run Queries**: Click the "Query" tab to write custom SQL commands

## 🖥️ Requirements

- macOS 11.0 (Big Sur) or later
- 50 MB free disk space
- Compatible with Intel and Apple Silicon Macs

## ❓ Frequently Asked Questions

**Can I edit database files in use by other programs?**  
Yes, but you should close the database in other apps first to avoid conflicts.

**Is my data safe?**  
QLite only reads and writes the files you explicitly open. It doesn't access other files.
